# AIYouMe 公式サイト コピー（現行方針）

目的: **初回相談の着手率を上げること**  
前提: 誇大表現なし、価格は公開面で固定数値を出さず、無料面談後に提案する。

## `/`

- Hero:
  - 眉: `AI + You + Me`
  - 見出し: `学習・制作・業務を、伴走と設計で回る状態へ。`
  - CTA: `無料相談する` / `お問い合わせ`
- Value:
  - 増やす: 再現できる実行手順、意思決定の明確さ、継続できる運用習慣
  - 減らす: 手戻り、属人化、やりっぱなし
- Method:
  - Diagnose → Design → Run → Review
- Divisions:
  - Learning / Studio / Automation

## `/learning`

- 主役導線。親子の不安を、実行できる計画へ変える。
- pricing 表現は `料金は支援範囲と頻度に応じて、無料面談後にご提案します。`
- CTA:
  - `LINEで無料面談を予約`
  - `Webで面談日程を確認`
- FAQ では価格を placeholder に戻さない。

## `/studio`

- 制作相談の窓口。
- CTA:
  - `LINEで制作相談`
  - `メールで問い合わせ`
- VOID-RUSH は `Studio 配下の実験コンテンツ` として説明し、主要サービスと混同させない。

## `/automation`

- 法人向け AI 自動化を、現場で回る仕組みにする。
- CTA:
  - `お問い合わせ`
  - `LINEで相談する`

## `/creator/void-rush/`

- 公開継続する実験コンテンツ。
- Studio の検証事例として扱い、ブランド全体の主導線には昇格させない。

## Legacy Routes

- `/education` → `/learning`
- `/creator` → `/studio`

移行ページでは noindex を維持し、旧導線を新導線へ安全に寄せる。
