# AIYouMe Brand Asset Matrix

## Variants

- `logo-dark`: light header, light editorial pages, canonical lockup
- `logo-light`: dark footer, inverse surfaces
- `logo-mono`: single-color use, print-safe fallback
- `mark`: service badge, small UI marker, favicon-adjacent placements
- `mark-mono`: grayscale or constrained contrast
- `symbol`: hero motif, large decorative use, OGP motif
- `lockup`: hero lead visual, branded explanatory placement

## Service Color Mapping

- `Learning`: orange (`You`)
- `Studio`: green (`Me`)
- `Automation`: blue (`AI`)

## Rules

- Header uses `logo-dark`
- Footer uses `logo-light`
- Hero explanation can use `lockup`
- Small pills and section badges use `mark`
- `symbol` is decorative, not the default navigation logo
